Clean a screenshot

This removes the hidden data a phone or an editor adds to a picture (EXIF, location, XMP, Photoshop data, colour profiles) and saves what you see as a clean PNG. Everything happens on this phone. The picture is never uploaded.

    Save clean PNG

    Then post it

    1. Save it to Files. Tap Save clean PNG. If a share sheet opens, choose Save to Files, not Save Image.
    2. Attach it from Files. In the GitHub comment, tap the paperclip, then Choose File, and pick the clean PNG from Downloads or the folder you chose.
    3. Never from Photos. Picking the picture from Photos lets the phone add hidden data again.
    Check this phone's browser

    This makes two test pictures full of hidden data, cleans them here and checks the results. It takes a few seconds and uses no picture of yours.
