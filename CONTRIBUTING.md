# Contributing

Useful documentation, client setup guidance, reproducible compatibility reports, and confirmed interface fixes are welcome.

## Before you open a pull request
1. Check [meku.farm/docs](https://meku.farm/docs) and [meku.farm/ai-access](https://meku.farm/ai-access) for the current contract.
2. Search existing issues and pull requests.
3. Keep the change focused and describe the evidence behind it.
4. Mark examples as untested unless you ran them against the live endpoint with an authorized key.
5. Never include keys, wallet credentials, personal information, or private mission details.

## Integration reports
Include client and version, environment, transport, redacted configuration, tool called, date, and observed result. Distinguish an internal test from an independent external test. Do not call a setup or attempt a success.

## Documentation style
- Treat the live MEKU docs as the source of truth.
- Explain whether an action reads data or writes a request.
- Explain human consent and operator review before showing the write tool.
- Do not claim completed work or payment without evidence.
- Keep examples free of secrets and label unverified client behavior.

By contributing, you agree your contribution may be included in this public repository. This repository does not currently assert separate license terms.
