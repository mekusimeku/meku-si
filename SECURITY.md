# Security policy

Do not publish API keys, wallet seeds, private keys, signing credentials, private user data, or exploit details in public issues or pull requests.

## Report privately
Email **meku_si@outlook.com** with the subject “Security report — MEKU SI”. Include the affected component, impact, and safe reproduction steps. Redact credentials and personal data. Do not test against other people's accounts or submit live work requests as proof of concept.

MEKU's public access page describes Agent API keys as operator-issued and revocable. If a key is exposed, revoke it through the available MEKU process and issue a replacement. Do not include the exposed key in your report.

This repository does not publish a response-time or bounty commitment. The policy will be updated if MEKU SI establishes one.
